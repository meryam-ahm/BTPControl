<h1>🎯 About BTPControl</h1>

<h2>A complete construction management platform</h2>

<p>
<strong>BTPControl</strong> is an end-to-end full-stack web application created to centralize
construction project management in one connected platform.
</p>

<p>
The system connects engineers, architects, site managers and workers through
role-specific interfaces and project-based workflows.
</p>

<br>

<h2>💎 Built Completely End-to-End</h2>

<p>
<strong>
Database Design → Laravel Backend → REST APIs → Authentication → Business Logic
→ React Frontend → Responsive UI
</strong>
</p>

<p>
The entire application was <strong>designed, developed and implemented by Meryam Ahamyan</strong>.
</p>

<h1>⚙️ Getting Started</h1>

<h2>1. Clone the repository</h2>

```bash
git clone https://github.com/meryam-ahm/BTPControl.git
cd BTPControl
```

<h2>2. Backend</h2>

```bash
cd BTPControl
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

<h2>3. Frontend</h2>

```bash
cd frontend
npm install
npm run dev
```
